# VeilVerse

Welcome to the VeilVerse.

I have created a dedicated page to showcase the working of all the scroll-based sequences, video transitions, and Interactive UI effects used in the landing page, letting you experience how beautiful and engaging elegance in motion can be. It is equipped with custom interactive displays and smooth styling.

The website is fully optimized for previews and shares across any platform, including a high-quality OG Image and custom favicon built-in.

---

## Getting Started

**Prerequisites:** Node.js 20.9+ (required by Next.js 16) and npm. No environment variables are needed.

```bash
git clone git@github.com:adilhusain01/veilverse.git
cd veilverse/client
npm install
npm run dev        # http://localhost:3000
```

Other scripts (run inside `client/`): `npm run build`, `npm start` (serve the production build), `npm run lint`.
